# Kisan Patrika — Marketing Material Downloads

Drop the print-ready files here with these exact names and they will be
served at `/downloads/<name>` and listed on the `/downloads` page:

| File name                          | Material      |
|------------------------------------|---------------|
| kisan-patrika-hoarding.pdf         | Hoarding      |
| kisan-patrika-visiting-card.pdf    | Visiting Card |
| kisan-patrika-pamphlet.pdf         | Pamphlet      |
| kisan-patrika-stickers.pdf         | Stickers      |
| kisan-patrika-store-banner.pdf     | Store Banner  |

Any web/print format works (pdf, jpg, png, zip) — if you use a different
extension, update `file` in `frontend/app/downloads/page.jsx` accordingly.
Files that are not present show as "Coming soon" on the page automatically.
