# KisanPatrika Dashboard

A graphical, non-technical home dashboard for the KisanPatrika platform. It visualizes the Marketplace + CRM + ERP + AI vision described in the product document.

## Tech Stack

- React 18
- Next.js 14 (App Router)
- Tailwind CSS
- Lucide React (icons)
- Recharts (charts)

## Getting Started

```bash
# 1. Install dependencies
npm install

# 2. Run the development server
npm run dev

# 3. Open the printed URL (default: http://localhost:3000)
```

## Build for Production

```bash
npm run build
npm run start
```

## Dashboard Highlights

- **KPI Cards**: Active listings, sales, orders, leads, store revenue, AI calls
- **Charts**: Revenue trend, sales by category, lead stages, monthly sales
- **Quick Access Modules**: AI platform, marketplace, store, buyers, membership, etc.
- **Omnichannel Channel Grid**: Chat, voice, WhatsApp, email, SMS, live agent
- **My Activity Timeline**: Chronological user events
- **Product Lifecycle Pipeline**: Visual status progression with counts

All components are static for now and can be wired to a backend API later.
